Oct 20, 2026 · @Leo · 10/22 修订：desert 提前重建并加入训练，决策节点移到 11/10，判据改为 H1/H2/不伤害

## 核心定位

HAD 和 SR3M 合并为一篇论文：SR3M 提出问题（地形 benchmark），HAD 的双视角融合给出答案。

论文故事：

1. 现有无人机 VLN benchmark 虽然包含自然地貌，但没有把地形复杂度作为核心变量来研究
2. SR3M 共 8 个场景 × 4 张地图 × 约 50 条轨迹（约 1,600 条）。有地形起伏的是 mountain 和 desert 两个场景：mountain 201 条路线按 AGL 分层，125 条指令要求随地形调整高度；desert 在 Blender 中按 mountain 的设计重建 4 张起伏地图，与其他场景一样 3 张进训练、1 张整图留出作未见地图评测
3. 实验发现：地形越复杂，只用前视角的方法性能下降越多
4. 俯视角提供了地势、坡向、离地高度等关键信息
5. 双视角融合方法针对性地解决这个问题

注意：多视角输入本身不新，OpenUAV 已经默认配置了 5 个视角。论文的卖点是"俯视角在什么情况下有用"的分析，加上以地形为核心的 benchmark。

模型路线：主模型用 ResNet 级别的轻量结构，可以写成"可机载部署的高效模型"；VLM 只作为零样本基线，通过 API 调用。

## 11/10 决策标准

在 val_unseen 的留出地图上（mountain 与 desert 各 1 张），比较 A（仅前视）和 B（前视 + 俯视）。判据在开训前固定，细节见 [protocol.md](protocol.md) §6。

| 结果 | 结论 | 下一步 |
| --- | --- | --- |
| H1：随地形路线上 B 的相对 dz 改善（1 − B/A）三个种子都为正，路线配对 95% CI 下界 > 0；H2：高坡段的相对改善大于低坡段；对照路线 B 不比 A 差超过 1cm | 核心假设成立 | 继续主线，冲 RA-L + IROS |
| 只有 H1 成立 | 俯视有用，但"越复杂越有用"未获支持 | 继续主线，主张限定为"地形跟随受益于俯视" |
| H1 不成立 | 双视角故事不成立 | 转向 benchmark 论文：系统评测现有方法在不同地形条件下的表现，HAD 作为基线；目标改为 Drones 等期刊 |
| 离线评测中 yaw 预测已塌缩成直飞 | 模型本身有问题 | 无论哪条路，接入闭环前必须先解决 |

不再用"125 条的提升大于 76 条"作判据：mountain 对照组全是平地定高路线，dz 几乎为 0，这个比较没有区分力。

## 可选支线：生成式外观增强与真实测试集

优先级低于沙漠重建，有余力再做，不阻塞主线；12/15 前做不成就留给下一篇论文或期刊扩展版。

做法：以 UE5 渲染的深度图、分割图或边缘图为条件，用生成模型只改变外观纹理、保留几何结构。只对一小部分帧做增强。位姿、动作、指令沿用仿真数据，前视和俯视来自同一场景，几何一致。

论文里的说法："生成式外观增强"，作为提升视觉鲁棒性的方法模块。生成图像必须明确标注为生成图像，不能称为真实图像。

结论的边界：

- 有真实测试集（几十条带图像、位姿、指令的轨迹）→ 可以声称提升了真实世界泛化能力
- 没有真实测试集 → 只能声称提升了对外观变化的鲁棒性

候选真实数据：UAV-Flow、AirNav 等公开真实无人机数据集；它们以城市场景为主，视角和地形是否匹配需要逐个核实。

## 风险与应对

| 风险 | 应对 |
| --- | --- |
| 地形起伏只集中在 mountain 一个场景 | 提前重建 desert 4 张起伏地图并加入训练（3 训练 + 1 留出），复用 mountain 的 AGL 流程 |
| 双视角在 SR3M 上没有提升（HAD 数据上已出现过） | 11/10 转向 benchmark 论文，不推倒重来 |
| desert 重建延期，挤压训练与写作 | 10/30 未完成采集就先用已完成的图；最晚 11/10 决策，离 2/20 投稿仍有余量 |
| 闭环中动作塌缩为直飞（在 OpenUAV 上出现过） | 离线阶段先查 yaw 预测分布，用平衡采样和加权处理；接闭环前必须解决 |
| 沙地纹理少，整体性能下降不一定来自地形 | 比较 desert 图内不同坡度区段，以及同起伏上的随地形/定高路线，而不是沙漠 vs 其他场景 |
| 沙漠地形被认为是人为挑选的 | 使用公开真实 DEM 或参数明确的程序化方法，每张地图的起伏程度可量化 |
| Cosys-AirSim 在 UE 5.8 上跑不通 | 预编译插件基于 UE 5.8.2，先确认小版本；备选 Project AirSim 1.1.0，或改用不依赖插件的位姿闭环 |
| RTX 3070 Laptop 只有 8GB 显存，且训练和渲染争用 | 主模型保持轻量（实测训练只占 0.85GB 显存）；沙漠渲染与训练错开夜晚；VLM 只用 API 零样本基线，必要时短期租云 GPU |
| 审稿人要求真机实验 | 闭环做扎实，论文中专门讨论 sim-to-real；有真实测试集时补充离线真实评测 |
